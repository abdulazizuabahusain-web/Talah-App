TASK 1 — PRODUCT ANALYTICS: MIXPANEL INTEGRATION
─────────────────────────────────────────────
Server-side (API):
1. Install mixpanel in the api-server package: `pnpm add mixpanel`
2. Create artifacts/api-server/src/lib/analytics.ts — a singleton Mixpanel client that:
   - Initialises only if MIXPANEL_TOKEN env var is set (fail silently in dev if absent)
   - Exports a single `track(event, userId, properties)` function
   - Never throws — wrap all calls in try/catch and log errors silently
   - Strips any PII before sending: no full names, no phone numbers, no raw device IDs
3. Add tracking calls at these exact points (nowhere else without explicit approval):
   - POST /api/auth/otp/send → track('otp_requested', anonymousId, { city })
   - POST /api/auth/otp/verify → track('otp_verified', userId, { city })
   - POST /api/users/me (profile completion) → track('profile_completed', userId, { city, hasPersonality: bool })
   - POST /api/groups (group request submitted) → track('group_requested', userId, { type: 'coffee'|'dinner', city })
   - PATCH /api/groups/:id/accept → track('match_accepted', userId, { groupId, city })
   - PATCH /api/groups/:id/decline → track('match_declined', userId, { groupId, city })
   - POST /api/groups/:id/feedback → track('feedback_submitted', userId, { rating, groupId })
4. Add MIXPANEL_TOKEN to .env.example

Client-side (Expo):
5. Install mixpanel-react-native in the lib/ frontend: `pnpm add mixpanel-react-native`
6. Create lib/src/lib/analytics.ts (client) that:
   - Only initialises and tracks if the user has accepted the analytics consent (read from a ConsentContext — create it if it doesn't exist)
   - Exports the same track() interface as the server module for consistency
   - Tracks these client-side events only: screen_view (screen name), app_opened, app_backgrounded, notification_tapped
7. Add a ConsentBanner component at lib/src/components/ConsentBanner.tsx that:
   - Shows on first launch before any tracking begins
   - Presents: "We collect anonymised usage data to improve Tal'ah. No personal information is shared." with Accept / Decline buttons in Arabic and English
   - Persists the choice to AsyncStorage under the key 'analytics_consent'
   - If declined: analytics module stays silent — no events, no network calls
