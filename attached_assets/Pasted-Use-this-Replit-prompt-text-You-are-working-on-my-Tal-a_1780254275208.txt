====================

1. Venue selection during Tal’ah request
Currently users may not have clear venue options.

New requirement:
When user requests a Tal’ah, allow them to select from pre-determined approved venues.

- preferred time

- city

- optionally area

Each venue should include:
- venueName
- city
- area
- type: coffee / dinner / both
- googleMapsUrl
- active boolean
- notes optional

If venue management table does not exist, create one.

Suggested table:
venues:
- id

- city
- area
- type

- updatedAt

Admin should be able to:
- view venues

MVP is enough. Do not overbuild.

2. Google Maps location link
====================

Venue location should be linked to Google Maps.

====================

Observed issue:
Dates are showing as Hijri in some locations of the Tal’ah request/status flow.

- Tal’ah request form
- Tal’ah request summary
- admin dashboard
- group creation
- confirmed Tal’ah screen
- Tal’ah status screen
- feedback screen
- created groups list

Recommended display:
Arabic UI:

or

English UI:
Wednesday, 12 June 2026
or
12/06/2026

Important:
Do not use Hijri calendar display.

If using Intl.DateTimeFormat, force Gregorian calendar:
- calendar: "gregory"
or use locale:
- ar-SA-u-ca-gregory

====================
6. Tal’ah status should auto-complete 2 hours after start time
====================

Requirement:
A Tal’ah/group status should automatically become completed two hours after its start time.

Logic:
If group status is confirmed/matched/revealed and current time >= meetupTime + 2 hours:
- update status to completed
or
- treat it as completed in UI and API response

Implementation options:
A. Simple MVP option:
On every relevant API call that fetches groups/status, run a helper function:
autoCompleteExpiredGroups()
This checks groups where meetupTime + 2 hours has passed and updates status to completed.

B. If current app supports scheduled jobs, use a scheduled job.
But MVP option A is acceptable.

Important:
- Do not complete cancelled groups.
- Do not complete already completed groups.
- Completion should unlock post-Tal’ah feedback and report member feature.
- Before completion, feedback should not be available.

User-facing status:
Before start:
- Confirmed

During first two hours after start:
- In progress / الطلعة جارية

After two hours:
- Completed / انتهت الطلعة
- Show feedback CTA
