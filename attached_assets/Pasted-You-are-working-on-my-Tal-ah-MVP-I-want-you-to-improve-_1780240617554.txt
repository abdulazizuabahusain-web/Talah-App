====================
NEW FEEDBACK FEATURE REQUIREMENTS
====================

The feedback flow should happen after a Tal’ah is completed.

Feedback should collect the minimum high-value signals only.

Recommended feedback questions:

1. Overall Comfort
Arabic:
كيف كان شعورك بالراحة أثناء الطلعة؟

English:
How comfortable did you feel during the Tal’ah?

Type:
1–5 rating

2. Group Fit
Arabic:
هل حسيت أن المجموعة مناسبة لك؟

English:
Did the group feel suitable for you?

Type:
Single choice:
- نعم، مناسبة جداً / Yes, very suitable
- إلى حد ما / Somewhat
- لا، ما كانت مناسبة / No, not suitable

3. Would Join Again
Arabic:
هل تود تجربة طلعة ثانية؟

English:
Would you join another Tal’ah?

Type:
Single choice:
- نعم / Yes
- ربما / Maybe
- لا / No

4. Venue Experience
Arabic:
كيف كان المكان للطلعة؟

English:
How was the venue for the Tal’ah?

Type:
1–5 rating

5. Venue Suitability
Arabic:
هل المكان مناسب لطلعات مستقبلية؟

English:
Is this venue suitable for future Tal’ahs?

Type:
Single choice:
- نعم / Yes
- ربما / Maybe
- لا / No

6. Optional Comment
Arabic:
أي ملاحظة تحب تضيفها؟

English:
Any comment you’d like to add?

Type:
Optional text

7. Safety Concern
Arabic:
هل واجهت أي موقف غير مريح أو يحتاج مراجعة؟

English:
Did anything uncomfortable happen that needs review?

Type:
Single choice:
- لا / No
- نعم / Yes

If Yes:
show optional text field:
Arabic:
اشرح لنا باختصار

English:
Briefly explain

====================
API REQUIREMENTS
====================

Review existing endpoints and update or create:

1. Submit feedback
POST /api/feedback

Request body:
- groupId
- userId
- comfortRating
- groupFit
- wouldJoinAgain
- venueRating
- venueSuitable
- comment
- safetyConcern
- safetyConcernDetails

Validation:
- groupId required
- userId required
- comfortRating required, integer 1–5
- groupFit required
- wouldJoinAgain required
- venueRating required, integer 1–5
- venueSuitable required
- safetyConcern required
- if safetyConcern = true, safetyConcernDetails should be optional but recommended

Duplicate prevention:
- if feedback already exists for same groupId + userId, return 409 conflict with clear error message.

2. Check feedback status
GET /api/feedback/status?groupId=...&userId=...

Return:
- submitted: true/false
- feedbackId if submitted
- submittedAt if submitted

3. Admin feedback list
GET /api/admin/feedback

Return all feedback with:
- feedback fields
- user nickname
- user gender
- user city
- group title
- group venue
- group meetupTime

4. Admin feedback by group
GET /api/admin/groups/:groupId/feedback

Return:
- group details
- all feedback for that group
- average comfortRating
- average venueRating
- count of wouldJoinAgain yes/maybe/no
- count of safety concerns
